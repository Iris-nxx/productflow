# ProductFlow

ProductFlow 是服务于产品全链路思考的本地网页工作台。围绕产品工作流，内置需求编撰、竞品解构、方案头脑风暴等专项能力；用户进入工作台后，输入核心议题，即可调度对应专项能力开展产品推演与文档产出。会话对话与产出文档一体化同屏，左侧沉淀历史项目完整上下文，可无缝接续往期研讨。

模型配置放在项目根目录的 `.env` 文件，兼容 OpenAI 格式聊天接口。**密钥仅服务端读取，不会下发到前端，浏览器无法获取密钥信息**。

## 适用人群

适合正在做产品定义的使用者：产品经理、独立开发者，或是需要自主把想法落地成正式文档的创作者。
定位场景：想法尚未固化成文档，需要先充分沟通、理清逻辑，再开始落笔输出。

## 核心能力

新建项目时选择工作模式，输入框附带对应场景提示示例；切换模式，示例会同步更新。

### 需求撰写

用于产出功能 PRD。流程：先完成需求澄清 → 界定需求边界 → 输出完整需求方案。访谈式引导，单次只确认一个问题，不编造未确认的技术细节。文档支持在线编辑、一键复制与下载。

### 头脑风暴

用于动手开发前梳理问题、收敛方案。先通过提问挖掘信息，再复述已达成共识的内容做校验，确认后整理成方案；也可以主动指令，跳过提问环节直接生成方案。

### 竞品调研

支持同时分析 2–5 款竞品。流程：确认竞品清单、调研目标、自身产品定位 → 从产品策略、功能能力、用户体验、增长方式多维度横向对比 → 输出结论：可借鉴点、需要规避的照搬风险、后续落地行动项。
信息不足时会主动补齐问询，不强行拼凑一份完整报告。

## 本地启动

依赖 Python 3 环境。

1. 将 `.env.example` 复制为 `.env`，填入接口地址、模型名称、密钥；`.env` 默认加入忽略清单，不会提交至代码仓库。
2. 在项目根目录执行启动命令：

```
python3 server.py
```

> 
> 修改 `.env` 配置后，需要重启服务生效。

3. 浏览器访问：[http://127.0.0.1:8765/](http://127.0.0.1:8765/)
